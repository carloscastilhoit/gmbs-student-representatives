# GMBS Student Representatives

Files for the GMBS student representatives contact page.

## Publish with GitHub Pages
1. Create a new public repository named `gmbs-student-representatives`.
2. Upload `index.html` and `carlos.png` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. The page should be available at:
   `https://carloscastilhoit.github.io/gmbs-student-representatives/`

When Gigi's photo is available, the placeholder can be replaced.
